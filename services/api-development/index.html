FAQ

Common questions about API development services

How much does it cost to develop an API?

It depends on the number of endpoints, the security requirements and the integrations involved. Our senior engineering is anchored at £850 per day, and most API projects are quoted as a fixed price after a scoping call, so you know the number before we start. A single integration costs far less than a full public API platform with authentication, documentation and SDKs.

How long does API development take?

A well-defined integration or small internal API can take days. A production API with authentication, rate limiting, documentation and a CI/CD pipeline typically takes weeks rather than months. Because we design the contract first, your frontend team can build against a mock while we implement, which shortens the overall timeline.

Should we use REST or GraphQL?

REST is the right default for most services: simple, cacheable and well aligned with HTTP semantics. GraphQL earns its place when many clients need different views of the same data, or when over-fetching is hurting mobile performance. We build both, and we will recommend one based on your data model and consumers rather than fashion.

Why is my API slow?

The database is usually involved: unindexed queries, connections opened per request, or endpoints returning far more data than the client needs. Payload size, chatty downstream calls and missing caching account for most of the rest. We measure first with profiling and traces, then fix the bottleneck that actually matters instead of guessing.

Can you tune an API you didn't build?

Yes. We reverse-engineer entire platforms, including open-source systems we did not build, to find the real cause of slowness. Past root causes include NGINX misconfigured for the ingress volume, under-specified RabbitMQ nodes, persistent volumes on slow disks, and over-provisioned resources wasting money without adding speed.

Do you handle third-party API integrations?

Yes. We connect products to payment providers, CRMs and enterprise systems, including Dataverse and Dynamics 365 feeds, with proper authentication, retries and monitoring built in. Where an official SDK is weak or missing, we write a clean client against the provider's API so the integration stays testable and maintainable.

Do you provide ongoing support after the API goes live?

Yes. Every build ends with a clean handover: documentation, runbooks and a walkthrough for your team. If you would rather we keep running things, our Application Care managed plan starts at £595 per month for monitoring plus one senior engineering day, with a three-month minimum term.
