What the engagement covers

Six steps, in this order

Creating the link is the short part. The work is in whatever reads the data, so that is where the engagement spends its time.

01

Inventory every consumer

Each report, semantic model, pipeline, notebook and serverless SQL view that reads the Synapse Link output, with an owner and a cut-over order. That list sets the size of the job.

02

Check capacity, choose tables

Dataverse database headroom checked in the Power Platform admin center, and a deliberate table list instead of the default, because every linked table consumes database storage.

03

Link side by side

Fabric Link created while Synapse Link carries on, with row counts reconciled table by table before anything is repointed.

04

Fix what reads the data

Serverless SQL moved to the Fabric SQL analytics endpoint, NULL and empty-string handling checked, and choice metadata queries updated for low-latency sync.

05

Repoint one consumer at a time

Starting with the reports that hurt least if they break, so nothing goes dark on cut-over day.

06

Retire last

The Synapse Link profile, Spark pool and storage account removed only once nothing reads them, so the old route is there until the new one is proven.

Where to move

Synapse Link with CSV, or Link to Fabric

Both are supported destinations for anyone leaving the Delta export. They are not the same thing, and the right one depends on what reads the data.

FAQ

Questions this usually raises

Is Azure Synapse Link for Dataverse being retired?

No. The service stays, with CSV export to your own storage account. What is going is its Delta Lake (Parquet) export option: closed to new customers from 15 October 2026 and removed in December 2027.

When do we have to move by?

If you use the Delta Lake (Parquet) export, by December 2027. If anything still depends on the older Export to Data Lake add-in for finance and operations, it stops on 30 November 2026 and Microsoft has said there will be no extensions.

Should we move to Fabric Link or to Synapse Link with CSV?

Fabric Link if the data is read by Power BI and Fabric. Synapse Link with CSV output if it is read by tools outside Microsoft, or has to sit in a lake you control under your own network rules.

Does Fabric Link cost more than Synapse Link?

It moves the cost rather than removing it. You stop paying for the storage account and the Spark pool that converts files to Delta, and start consuming Dataverse database capacity for the replica, plus Fabric capacity to use it. Which is cheaper depends on how many tables you link and how much database capacity you have spare.

How is the migration priced?

As a fixed price agreed after a short scoping call. The size of the job is set by how many reports and pipelines read the data, not by its volume, so that is what we look at first. Day-rate work is £850 a day if you would rather.

Have you done this before?

Yes. We have moved a production Dataverse estate from Azure Synapse Link to Link to Microsoft Fabric, and the six steps on this page are how we would run yours.
